별점은 교차로·차로 선택·시야 제한·경사·고속 합류·요금소 절차를 기준으로 한 게임의 코스 평가입니다. 카드 아래에 평가 이유를 표시합니다. 교통량은 한산(8대)·보통(28대)·혼잡(최대 80대)로 별도 선택합니다. 소요 시간은 코스 설계 예상치로, 운전 속도와 정차·혼잡·주차 시도에 따라 늘어납니다. 강제로 10분에 종료하거나 운전을 건너뛰지는 않습니다.

도심은 OSM의 실제 도로와 건물 윤곽을 바탕으로 상가·보도·옥상·전신주·가로수·횡단보도를 추가합니다. GSI 항공사진과 표고 타일 252장을 코스별로 저장했습니다. 알려진 건물 높이·층수를 우선하고, 미등록 높이·외벽·간판·식재·시설은 대표 형태의 자체 모델입니다. 실사 거리 사진을 그대로 재현하거나 건물 외관의 정확성을 보장하지 않습니다. 교량·터널의 별도 상판 높이는 아직 재현하지 않았습니다. 차량도 사진 기반 자체 모델이며 CAD 모델이 아닙니다.

E58는 저장된 실제 고속도로 곡선을 일부 사용하되 진입·출구·요금소를 짧게 재구성한 연습 코스입니다. 특정 실제 IC의 배치가 아닙니다. ETC는 20 km/h 이하로 감속하고 열린 차단기를 통과합니다. 일반 차로는 입구·출구에서 정차한 뒤 Enter 또는 화면 버튼으로 통행권·모의 정산을 처리합니다. 실제 결제는 없습니다. 신호의 위치를 지도에서 참고하되 주기·화살표·점멸 운영은 연습용입니다.

운전석은 차종별로 구분합니다. 프리우스는 낮은 시점과 중앙 계기판, 알파드는 높은 시점과 운전대 앞 계기판입니다. 모델의 기본 눈높이는 각각 1.10m / 1.46m이며 사진을 참고한 추정값입니다. 알파드는 시선 각도와 운전대 높이를 별도로 조정했습니다. 동일한 시야각에서도 도로를 보는 높이가 달라지며, 허용된 좌석 앞뒤·높이와 조향 범위에서 속도 숫자가 가려지지 않는지 광선 교차 테스트로 확인합니다.

스마트폰·태블릿은 화면 방향과 터치 입력 여부에 따라 운전 배치가 바뀝니다. 속도는 상단에 38–52px 숫자로 표시하고, 조향·페달·기어를 분리했습니다. 보조 미러는 가장자리의 작은 화면으로 표시하며 세로 화면에서는 양쪽을 보여 줍니다. 세로 시야는 천장과 발밑만 넓게 보이지 않도록 수직 90° 이내로 제한합니다. 화면 회전으로 코스·차량·운전 상태가 초기화되지는 않습니다. 위반 경고도 속도계를 가리지 않는 위치에 표시합니다.

0.9에서는 도심·마을 8개 코스를 실제 도로 그래프 위에서 다시 구성했습니다. 각 코스에 좌·우회전을 반복하고 직선 구간은 최장 180m 이하입니다. 대향차와 교차 차량을 여러 도로에 나누어 배치하며, 일반 녹색에서 우회전하는 AI는 대향차를 기다립니다. 회전 중 대향차로를 가로지르는 정상 동작은 역주행으로 판정하지 않고 회전 후 차로를 확인합니다.

신호 있는 횡단보도의 보행자는 건널 시간이 남은 녹색에서 출발합니다. 신호 없는 횡단보도에서는 대기 보행자에게 양보하며 AI도 멈춘 뒤 다시 출발합니다. 보행자는 차량을 통과하지 않고, 경찰관은 차도 밖 보도에서 순찰하는 인물로 표시합니다. 수신호 통제나 검문은 구현하지 않았습니다. 인물 배치와 일부 횡단보도는 연습 상황입니다. [경찰청 보행자 우선](https://www.npa.go.jp/bureau/traffic/oudanhodou/info.html), [우회전 화살표 신호 지침](https://www.npa.go.jp/laws/notification/koutuu/kisei/kisei20240326_2.pdf)을 참고했습니다.

주차는 초록색 P 목표면에 차량 전체를 넣고 1초 정차하면 완료합니다. 신호 주기는 연습에 맞게 줄였고 흰 정지선·횡단보도와 회전 유도선을 강조했습니다. 내비는 진행 방향을 위로 유지하며 회전 접근 시 자동 확대·다음 회전 강조를 합니다. Google Maps SDK를 사용하지 않는 자체 지도 화면입니다. 모바일 가로 화면은 양쪽 아래 조작 배치이며, 브레이크와 D/R 기어의 두 손가락 입력을 독립 처리합니다.

## 실행

Windows에서는 `start-game.bat`을 더블클릭하면 서버가 켜지고 브라우저가 열립니다. 다른 환경에서는 이 폴더에서 `node server.mjs`를 실행한 뒤 http://127.0.0.1:8000 을 엽니다. 별도 패키지 설치는 없습니다. 브라우저의 그래픽 가속이 필요합니다.

0.9는 6개 지역의 11개 코스를 동봉합니다. 도시별 좌표계와 표고를 전환하며, 오키나와 해안선을 다른 도시에 적용하지 않습니다. 신주쿠의 유리 외벽과 고층 건물, 교토의 저층 지붕, 오도리 공원 등은 지도 윤곽·알려진 높이와 지역별 건축 처리를 조합합니다. 개별 상점의 외관과 모든 입체교차로를 실측 재현한 것은 아닙니다.

교차로 신호등은 접근 방향마다 독립된 위치에 표시하며, 표시된 신호와 AI 차량의 정지선·신호 주기를 공유합니다. 지도에서 신호 정보가 부족한 주요 교차로는 `practice: true`로 구분한 연습용 신호를 추가합니다. 도로 옆 기둥과 신호등 지지대는 모든 교차 도로의 차도 폭을 검사해 배치합니다. AI는 다른 방향 차량을 무조건 앞차로 판단하지 않으며, 교차로를 통과 중인 차가 빠져나온 뒤 다음 차량이 진입합니다. 차로 전환 뒤의 실제 차체 충돌도 검사합니다.

휴대기기에는 항상 접근 가능한 **전체화면** 버튼, 44px 이상 조작 버튼, 노치·홈 표시줄 여백을 적용했습니다. 주소창이 변해도 동적 화면 높이를 따릅니다. 회전·앱 전환 시 페달 입력을 해제하고 일시정지합니다. iPhone 등 요소 전체화면을 지원하지 않는 환경은 Safari에서 **공유 → 홈 화면에 추가** 후 실행하는 방법을 안내합니다. 화면 배치는 데스크톱 브라우저에서 320×568, 390×844, 568×320, 844×390, 768×1024 크기로 검증했습니다. 실제 휴대기기의 그래픽 성능과 브라우저별 전체화면 동작은 추가 확인이 필요합니다.

## 이전 버전 및 장거리 지도 기능 기록

아래는 기존 0.5–0.6의 기능·운영 기록입니다. 0.7의 기본 플레이는 위의 저장된 짧은 코스를 사용합니다.

0.5에서는 지형·도로·차량의 높이를 같은 삼각형 노면에서 계산합니다. 긴 도로 구간과 항공사진을 지형 격자에 맞춰 분할해 땅에 묻히던 도로를 수정했고, 차량은 네 바퀴의 지지 높이로 경사와 기울기를 맞춥니다. 이동 중 지형 격자가 바뀌어도 노면 높이는 유지됩니다. 본섬 전역의 기본 GSI 표고 타일 23장과 모토부 세부 표고를 부드럽게 연결했습니다. 교량·터널의 별도 도로 상판 높이는 아직 재현하지 않았습니다.

0.6에서는 사용자가 첨부한 두 실내 사진을 기준으로 차량 모델을 구분했습니다. 프리우스는 4세대형의 중앙 계기판·세로형 센터 패널·흰색 기어 패널·파란 전자식 기어 레버·원형 운전대를 반영했습니다. 차체 크기와 회전 반경도 해당 세대의 2WD 15인치 기준으로 변경했습니다. 알파드는 첨부 사진의 브라운 내장·우드 장식·운전대 뒤 계기판·통합 공조 조작부·넓은 콘솔로 구성합니다. 화면·부품 위치·눈높이·세부 곡면은 사진 비율을 참고한 추정값이며 실차 CAD 치수는 아닙니다. 사진만으로 정확한 연식·등급·옵션을 확정하지 않습니다.

## 여러 명이 함께 사용할 때 (수업·단체, 수백 명)

수십~수백 명이 동시에 할 때 멈추거나 지도 오류가 나지 않게 하려면 **수업 전에 한 번** 아래 순서로 준비하세요.

1. **오프라인 지도 받기:** 인터넷이 되는 PC에서 `build-offline-map.bat`을 더블클릭합니다. 본섬 전체의 도로(2km 타일 429개)와 추천 장소 주변 주차장을 `data/service-cache`에 저장합니다. 공개 지도 서버에 무리를 주지 않도록 하나씩 받으므로 30~60분쯤 걸립니다. 중간에 끊겨도 다시 실행하면 빠진 것만 받습니다.
   - 오프라인 지도가 있으면 **경로도 게임 서버가 직접 계산**합니다(내장 경로 계산기, `local-router.mjs`). 이때부터는 공개 지도·경로 서버 없이 게임이 돌아갑니다. 일방통행과 도로 속도는 반영하지만, 회전 금지 정보는 반영하지 않습니다.
   - 오프라인 지도가 없으면 공개 서버를 먼저 쓰고, 실패하면 저장된 도로로 내장 계산기를 씁니다. 공개 서버는 같은 인터넷 주소에서 동시에 몇 건만 받아 주므로, 많은 인원이 쓸 때는 꼭 미리 받아 두세요.
2. **실행 방식 선택**
   - **PC마다 실행:** 준비된 게임 폴더 전체(`data/service-cache` 포함)를 각 PC에 복사하고 `start-game.bat`을 실행합니다.
   - **서버 한 대로 공유:** `start-classroom-server.bat`을 실행하면 창에 `http://192.168.x.x:8000` 같은 주소가 나옵니다. 같은 네트워크의 다른 PC는 그 주소로 접속합니다. CPU 코어 수만큼(최대 8개) 작업자를 띄우고, 작업자가 멈추면 바로 다시 시작합니다. Windows 방화벽 창이 뜨면 '개인 네트워크'를 허용하세요.
3. **부하 확인:** `node scripts/load-test.mjs 500`은 500명이 동시에 게임을 여는 상황을 흉내 냅니다. 이 버전은 개발 환경(2코어)에서 300명(요청 10,200건)과 500명(17,000건) 모두 실패 0건이었고, 응답의 95%가 각각 0.45초, 0.6초 안에 왔습니다. 실제 수업 네트워크 속도는 따로 확인하세요(500명이 처음 접속할 때 약 530MB를 내려받습니다).

동시 사용을 위한 처리: 지도 요청은 한 줄로 대기하지 않고 타일 단위로 저장·공유됩니다. 외부 서버로는 지도 2건·경로 4건까지만 동시에 보내고, 혼잡 응답(429/502/503/504)은 한 번 다시 시도합니다. 정적 파일과 API 응답은 한 번만 직렬화·압축(gzip)해 재사용하고 ETag로 캐시를 확인합니다. 브라우저에서는 예기치 않은 오류가 생겨도 화면이 멈추지 않으며, 느린 PC에서는 해상도·그림자·미러 갱신 빈도를 자동으로 낮춥니다.

## 0.6 변경 사항

- **운전석 시점**: rFactor 2·Assetto Corsa·City Car Driving 같은 시뮬레이터처럼 실제 운전자 머리 위치에 카메라를 둡니다. 눈 위치를 14cm 앞으로 옮기고(운전대 중심까지 약 0.57m), 수평 시야각을 103°에서 86°로 줄여 뒷좌석에서 운전하는 듯한 느낌을 없앴습니다. ‘시야 설정’에서 시야각(60–100°), 좌석 앞뒤·높이를 조절할 수 있고 브라우저에 저장됩니다.
- **사이드미러**: 미러를 A필러 하단 뒤쪽 도어 벨트라인으로 옮기고, 실내에 있던 미러 암을 유리 바깥으로 옮겼습니다. 운전자 눈에서 미러 유리까지 광선 검사를 해, 기본 좌석에서 92% 이상, 좌석 조절 범위 전체에서 75% 이상 보이도록 테스트합니다. 우핸들 차의 왼쪽 미러는 정면에서 약 50° 왼쪽에 있으므로 Q로 고개를 돌려 보거나 왼쪽 보조 화면으로 봅니다.
- **페달과 변속**: 키를 누른 시간에 따라 페달이 깊어집니다(짧게 = 약하게). D·R에서 브레이크를 떼면 하이브리드 자동변속 차량처럼 시속 약 6km로 움직이므로(크립) 정차 중에는 S를 유지해야 합니다. 출발 시 주차 브레이크가 걸려 있습니다. 후진은 약 15km/h로 제한되고, 최고속도는 고속도로 주행이 가능하도록 올렸습니다.
- **방향지시등**: Z/X. 운전대를 돌렸다 풀면 자동으로 꺼집니다. 경로상 좌·우회전 30m 전부터 켜지 않으면 감점합니다(일본 도로교통법 기준).
- **공정한 판정**: 차량끼리 서로 통과하지 않습니다. 플레이어가 움직여 부딪친 경우에만 접촉 감점합니다. 일시정지 표지는 OSM 방향 정보에 따라 해당 진행 방향에만 적용하고, 지나간 뒤 다시 확인합니다.
- **교통 AI**: 교차로에서 회전하고, 회전 전에 감속하며, 막다른 길에서는 되돌아갑니다. 노란 신호에서 정지할 수 없거나 이미 정지선을 지났으면 교차로를 빠져나갑니다. 플레이어 차량으로 파고들지 않습니다.
- **실제 건물**: 출발지와 주행 경로 주변의 OpenStreetMap 건물 윤곽을 도로처럼 2km 타일 단위로 불러와 세웁니다. 높이·층수 정보가 있으면 그 높이로, 없으면 1층 높이(3.1m)로 표시합니다. 지붕만 있는 구조물(주유소 캐노피·차고)은 제외합니다. 건물은 외벽 질감별로 합쳐 그리므로 도심에서도 가볍습니다. 매달 받는 오프라인 지도 묶음에도 건물이 포함되며, 건물을 받지 못해도 운전은 그대로 시작됩니다.
- **영어 화면**: 타이틀과 상단의 한국어 / English 버튼으로 전환합니다.
- **소리**: 하이브리드 모터음, 노면 소음, 방향지시등 릴레이, 후진 경고음, 위반 알림, 접촉음(Web Audio, 파일 없음).
- **그래픽**: 태양·구름·지평선 연무가 있는 하늘, 아스팔트·연석·잔디 질감, 층과 창 간격에 맞춘 건물 외벽, 차량을 따라가는 선명한 그림자. 건물 창문을 개별 물체 대신 질감으로 그려 더 가벼워졌습니다.

## 드라이브 흐름

타이틀 → 지역 → 차량 → 출발지 → 목적지 → 교통량 → 출발 확인 → 직접 주행 → 목적지 주차 → 운전 점수.

상단 단계 버튼으로 이전 단계와 이미 완료한 단계에 바로 이동할 수 있습니다. 미완료 단계는 다음 버튼으로 차례로 진행합니다. 장소는 옆으로 넘기는 카드로 선택하고, 종류·지역·이름으로 검색할 수 있습니다. 준비 중에는 주차장 확인, 경로 계산, 주변 도로 준비 단계를 표시하고 경과 시간·취소·재시도를 제공합니다. 공개 지도 응답은 30초 후 오류를 표시합니다. 경로 준비를 취소한 뒤 늦게 도착한 응답으로 갑자기 운전을 시작하지 않습니다.

신호등·교차로·주차는 하나의 드라이브 안에 포함합니다. 별도 연습 모드는 없습니다. `tests/render-check.html`은 개발 검증용 화면이며 게임 메뉴에는 노출하지 않습니다.

‘지도 서비스가 제한 시간 안에 응답하지 않았다’는 것은 외부 서버에서 주차장이나 경로 정보를 받아오지 못했다는 뜻입니다. 도로·주차장은 Overpass API(공개 서버 3곳을 차례로 시도)로 필요한 도로만 조회하고, 모두 실패하면 OSM 지도 API를 약 1km 단위로 나누어 조회합니다(도심처럼 데이터가 많으면 더 잘게 나눕니다). 자동차 경로는 FOSSGIS OSRM을 우선 사용한 뒤 다른 OSRM 서버로 전환합니다. 성공한 공개 지도 응답을 로컬에 저장해 재사용합니다. 준비 취소는 해당 요청만 중단하며, 새 시도나 다른 대기 요청에 취소 상태를 넘기지 않습니다. 실제 자동차 경로가 없거나 조회가 실패하면 임의의 직선 도로를 만들지 않습니다.

## 현재 기능

- 실제 OSM 해안선으로 구분한 오키나와 본섬 전체 장소 검색, 추천 장소 28곳(오달렌터카 나하공항점 추가). 숙소·식당·관광지·쇼핑·교통시설을 포함합니다. 고우리섬 목적지는 대교로 연결되는 별도 섬으로 표시합니다.
- 오키나와 우선, 도쿄·후쿠오카는 각 도심 반경 2.5km 기본 검색 범위입니다.
- 프리우스 4세대형 2WD 15인치 기준(전장 4,540mm, 전폭 1,760mm, 축거 2,700mm, 최소 회전 반경 5.1m), 알파드 4세대형 브라운 실내·18인치 기준. 공식 전장·전폭·축거·최소 회전 반경을 사용한 저속 조향 모델입니다. 눈높이·조향 감각·가감속과 실내 세부 치수는 추정입니다.
- 차종별 우핸들 대시보드, 운전대 버튼, 계기판, 실내 중앙 내비게이션, 양쪽 사이드미러와 룸미러. 실내는 계속 다듬고 있는 자체 모델입니다.
- 내비게이션은 차량 위치·방향을 따라가며 교차로와 주차장 주변에서 확대됩니다. M 또는 화면 버튼으로 실내 화면을 가까이 볼 수 있습니다.
- 정차 후 R 후진을 선택하면 같은 실내 화면이 후방카메라로 바뀝니다. 빨강 약 0.5m, 노랑 약 1m 거리 표시와 파란 고정 차폭, 조향에 따라 휘는 노란 예상 경로를 표시합니다.
- 교통량은 쉬움 8대, 보통 28대, 어려움 최대 80대입니다. 실제 지도 도로에서 왼쪽으로 이동하고, 앞차·신호에 따라 감속합니다. 교통량과 신호 주기는 연습용 시뮬레이션이며 실제 교통 정보가 아닙니다.
- 모토부 테스트 구간의 건물 윤곽 120개와 주차장 영역 8곳, 차탄 숙소 주변 건물 153개, GSI 항공사진과 표고 자료를 사용합니다. 건물 높이는 알려진 값 또는 층수 기반 추정이며 외관·차선·도로 폭 일부는 단순화했습니다.
- 하나사키 마르셰 공용 주차장에는 항공사진에서 판독한 주차면 3개를 연결했습니다. 현장 실측값이 아닙니다. 목표 주차면에 차체 전체가 들어가고, 각도가 맞고, 완전히 멈춘 뒤 주차 브레이크를 2초 유지해야 완료합니다.
- 아쿠아 팰리스 차탄은 공식 안내에서 숙소 전용 주차장 존재를 확인하고, 항공사진에서 판독한 숙소 북서쪽 주차장 영역으로 연결했습니다. 개별 주차선·정확한 출입구와 내부 통로는 현장 검증 전입니다. 다른 목적지는 지도에 확인되는 공개 주차장 영역을 찾아 안내합니다. 아직 확인되지 않은 주차장을 임의 생성하지 않습니다.
- 휴대폰 크기에서는 장소 카드 스와이프와 터치 조향·가속·제동·기어·주차 브레이크를 지원합니다. 세로 화면에서는 도로가 크게 보이도록 시야를 바꾸고 양쪽 미러 영상을 보조 표시합니다. 운전 시 가로 화면이 더 넓은 시야를 제공합니다.

## 속도·단속카메라·운전 점수

지도에 등록된 제한속도와 방향별 제한속도를 우선 적용합니다. 미확인 구간은 숫자를 추측하지 않고 ‘표지 확인’으로 표시합니다. 2026년 9월 1일부터 중앙선 등이 없는 생활도로의 법정속도가 30km/h로 변경된 규정을 참고했으며, 해당 조건이 명시된 지도 자료에만 기본값을 적용합니다. 표지로 지정된 속도가 우선합니다.

일본에는 과속 자동 단속장비가 있으며 오키나와 경찰의 이동식 장비 운영 자료도 확인했습니다. OSM에 등록된 카메라 8곳을 위치 자료로 연결했습니다. 일부 조사 연도가 오래되어 현재 운영 여부는 확인되지 않았습니다. 누락된 카메라와 이동식 장비 위치를 임의로 만들지 않았습니다. 카메라·일시정지 표지의 장비 모양과 도로변 배치는 단순화되어 있습니다.

제한속도 초과, 신호 위반, 대향차로·일방통행 역주행, 일시정지 미준수, 차량·시설 접촉에 대해 경고와 감점을 표시합니다. 연속된 같은 위반으로 매 프레임 점수가 차감되지는 않습니다. 주차 완료 시 총점, 항목별 횟수·감점, 이동 거리와 시간이 나타납니다. 이는 게임의 연습 평가이며 실제 범칙금·벌점·단속 기준을 의미하지 않습니다. 모든 법규와 보행자 상황을 구현한 운전 교육 인증 프로그램은 아닙니다.
