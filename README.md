# 일본 드라이브 · 테스트 0.6

오키나와 본섬을 우선 개발하는 실제 지도 기반 1인칭 운전 웹앱입니다. 도로와 경로에는 실제 좌표를 사용합니다. 차량·거리 외관은 공식 사진과 지도 자료를 참고한 자체 3D 모델이며, 실차 CAD나 현장 사진 측량 수준의 정밀 재현은 아닙니다.

## 실행

이 폴더에서 `node server.mjs`를 실행한 뒤 http://127.0.0.1:8000 을 엽니다. 별도 패키지 설치는 없습니다. 브라우저의 그래픽 가속이 필요합니다.

가장 빠른 확인 코스는 **Sunset Resort Canphou → 카이호우마루**입니다. 마지막 확인 화면의 ‘추천 코스로 변경’으로 선택할 수 있습니다. 실제 도로 경로 543.2m, 출발 주변 도로와 실제 공용 주차장 자료를 저장했습니다. **Sunset Resort Canphou → Aqua Palace Chatan**의 실제 자동차 경로 70,170.7m도 저장해 준비 화면에서 곧바로 출발할 수 있습니다. 멀리 이동할 때 추가로 필요한 도로는 공개 지도 서비스 연결이 필요합니다.

0.5에서는 지형·도로·차량의 높이를 같은 삼각형 노면에서 계산합니다. 긴 도로 구간과 항공사진을 지형 격자에 맞춰 분할해 땅에 묻히던 도로를 수정했고, 차량은 네 바퀴의 지지 높이로 경사와 기울기를 맞춥니다. 이동 중 지형 격자가 바뀌어도 노면 높이는 유지됩니다. 본섬 전역의 기본 GSI 표고 타일 23장과 모토부 세부 표고를 부드럽게 연결했습니다. 교량·터널의 별도 도로 상판 높이는 아직 재현하지 않았습니다.

0.6에서는 사용자가 첨부한 두 실내 사진을 기준으로 차량 모델을 구분했습니다. 프리우스는 4세대형의 중앙 계기판·세로형 센터 패널·흰색 기어 패널·파란 전자식 기어 레버·원형 운전대를 반영했습니다. 차체 크기와 회전 반경도 해당 세대의 2WD 15인치 기준으로 변경했습니다. 알파드는 첨부 사진의 브라운 내장·우드 장식·운전대 뒤 계기판·통합 공조 조작부·넓은 콘솔로 구성합니다. 화면·부품 위치·눈높이·세부 곡면은 사진 비율을 참고한 추정값이며 실차 CAD 치수는 아닙니다. 사진만으로 정확한 연식·등급·옵션을 확정하지 않습니다.

## 0.6 변경 사항

- **운전석 시점**: rFactor 2·Assetto Corsa·City Car Driving 같은 시뮬레이터처럼 실제 운전자 머리 위치에 카메라를 둡니다. 눈 위치를 14cm 앞으로 옮기고(운전대 중심까지 약 0.57m), 수평 시야각을 103°에서 86°로 줄여 뒷좌석에서 운전하는 듯한 느낌을 없앴습니다. ‘시야 설정’에서 시야각(60–100°), 좌석 앞뒤·높이를 조절할 수 있고 브라우저에 저장됩니다.
- **사이드미러**: 미러를 A필러 하단 뒤쪽 도어 벨트라인으로 옮기고, 실내에 있던 미러 암을 유리 바깥으로 옮겼습니다. 운전자 눈에서 미러 유리까지 광선 검사를 해, 기본 좌석에서 92% 이상, 좌석 조절 범위 전체에서 75% 이상 보이도록 테스트합니다. 우핸들 차의 왼쪽 미러는 정면에서 약 50° 왼쪽에 있으므로 Q로 고개를 돌려 보거나 왼쪽 보조 화면으로 봅니다.
- **페달과 변속**: 키를 누른 시간에 따라 페달이 깊어집니다(짧게 = 약하게). D·R에서 브레이크를 떼면 하이브리드 자동변속 차량처럼 시속 약 6km로 움직이므로(크립) 정차 중에는 S를 유지해야 합니다. 출발 시 주차 브레이크가 걸려 있습니다. 후진은 약 15km/h로 제한되고, 최고속도는 고속도로 주행이 가능하도록 올렸습니다.
- **방향지시등**: Z/X. 운전대를 돌렸다 풀면 자동으로 꺼집니다. 경로상 좌·우회전 30m 전부터 켜지 않으면 감점합니다(일본 도로교통법 기준).
- **공정한 판정**: 차량끼리 서로 통과하지 않습니다. 플레이어가 움직여 부딪친 경우에만 접촉 감점합니다. 일시정지 표지는 OSM 방향 정보에 따라 해당 진행 방향에만 적용하고, 지나간 뒤 다시 확인합니다.
- **교통 AI**: 교차로에서 회전하고, 회전 전에 감속하며, 막다른 길에서는 되돌아갑니다. 노란 신호에서 정지할 수 없거나 이미 정지선을 지났으면 교차로를 빠져나갑니다. 플레이어 차량으로 파고들지 않습니다.
- **소리**: 하이브리드 모터음, 노면 소음, 방향지시등 릴레이, 후진 경고음, 위반 알림, 접촉음(Web Audio, 파일 없음).
- **그래픽**: 태양·구름·지평선 연무가 있는 하늘, 아스팔트·연석·잔디 질감, 층과 창 간격에 맞춘 건물 외벽, 차량을 따라가는 선명한 그림자. 건물 창문을 개별 물체 대신 질감으로 그려 더 가벼워졌습니다.

## 드라이브 흐름

타이틀 → 지역 → 차량 → 출발지 → 목적지 → 교통량 → 출발 확인 → 직접 주행 → 목적지 주차 → 운전 점수.

상단 단계 버튼으로 이전 단계와 이미 완료한 단계에 바로 이동할 수 있습니다. 미완료 단계는 다음 버튼으로 차례로 진행합니다. 장소는 옆으로 넘기는 카드로 선택하고, 종류·지역·이름으로 검색할 수 있습니다. 준비 중에는 주차장 확인, 경로 계산, 주변 도로 준비 단계를 표시하고 경과 시간·취소·재시도를 제공합니다. 공개 지도 응답은 30초 후 오류를 표시합니다. 경로 준비를 취소한 뒤 늦게 도착한 응답으로 갑자기 운전을 시작하지 않습니다.

신호등·교차로·주차는 하나의 드라이브 안에 포함합니다. 별도 연습 모드는 없습니다. `tests/render-check.html`은 개발 검증용 화면이며 게임 메뉴에는 노출하지 않습니다.

‘지도 서비스가 제한 시간 안에 응답하지 않았다’는 것은 외부 서버에서 주차장이나 경로 정보를 받아오지 못했다는 뜻입니다. 도로·주차장은 작은 범위의 OSM 지도 조회로 처리하고, 자동차 경로는 FOSSGIS OSRM을 우선 사용한 뒤 다른 OSRM 서버로 전환합니다. 성공한 공개 지도 응답을 로컬에 저장해 재사용합니다. 준비 취소는 해당 요청만 중단하며, 새 시도나 다른 대기 요청에 취소 상태를 넘기지 않습니다. 실제 자동차 경로가 없거나 조회가 실패하면 임의의 직선 도로를 만들지 않습니다.

## 현재 기능

- 실제 OSM 해안선으로 구분한 오키나와 본섬 전체 장소 검색, 추천 목적지 27곳. 숙소·식당·관광지·쇼핑·교통시설을 포함합니다. 고우리섬 목적지는 대교로 연결되는 별도 섬으로 표시합니다.
- 오키나와 우선, 도쿄·후쿠오카는 각 도심 반경 2.5km 기본 검색 범위입니다.
- 프리우스 4세대형 2WD 15인치 기준(전장 4,540mm, 전폭 1,760mm, 축거 2,700mm, 최소 회전 반경 5.1m), 알파드 4세대형 브라운 실내·18인치 기준. 공식 전장·전폭·축거·최소 회전 반경을 사용한 저속 조향 모델입니다. 눈높이·조향 감각·가감속과 실내 세부 치수는 추정입니다.
- 차종별 우핸들 대시보드, 운전대 버튼, 계기판, 실내 중앙 내비게이션, 양쪽 사이드미러와 룸미러. 실내는 계속 다듬고 있는 자체 모델입니다.
- 내비게이션은 차량 위치·방향을 따라가며 교차로와 주차장 주변에서 확대됩니다. M 또는 화면 버튼으로 실내 화면을 가까이 볼 수 있습니다.
- 정차 후 R 후진을 선택하면 같은 실내 화면이 후방카메라로 바뀝니다. 빨강 약 0.5m, 노랑 약 1m 거리 표시와 파란 고정 차폭, 조향에 따라 휘는 노란 예상 경로를 표시합니다.
- 교통량은 쉬움 8대, 보통 28대, 어려움 최대 80대입니다. 실제 지도 도로에서 왼쪽으로 이동하고, 앞차·신호에 따라 감속합니다. 교통량과 신호 주기는 연습용 시뮬레이션이며 실제 교통 정보가 아닙니다.
- 모토부 테스트 구간의 건물 윤곽 120개와 주차장 영역 8곳, 차탄 숙소 주변 건물 153개, GSI 항공사진과 표고 자료를 사용합니다. 건물 높이는 알려진 값 또는 층수 기반 추정이며 외관·차선·도로 폭 일부는 단순화했습니다.
- 하나사키 마르셰 공용 주차장에는 항공사진에서 판독한 주차면 3개를 연결했습니다. 현장 실측값이 아닙니다. 목표 주차면에 차체 전체가 들어가고, 각도가 맞고, 완전히 멈춘 뒤 주차 브레이크를 2초 유지해야 완료합니다.
- 아쿠아 팰리스 차탄은 공식 안내에서 숙소 전용 주차장 존재를 확인하고, 항공사진에서 판독한 숙소 북서쪽 주차장 영역으로 연결했습니다. 개별 주차선·정확한 출입구와 내부 통로는 현장 검증 전입니다. 다른 목적지는 지도에 확인되는 공개 주차장 영역을 찾아 안내합니다. 아직 확인되지 않은 주차장을 임의 생성하지 않습니다.
- 휴대폰 크기에서는 장소 카드 스와이프와 터치 조향·가속·제동·기어·주차 브레이크를 지원합니다. 세로 화면에서는 도로가 크게 보이도록 시야를 바꾸고 양쪽 미러 영상을 보조 표시합니다. 운전 시 가로 화면이 더 넓은 시야를 제공합니다.

## 속도·단속카메라·운전 점수

지도에 등록된 제한속도와 방향별 제한속도를 우선 적용합니다. 미확인 구간은 숫자를 추측하지 않고 ‘표지 확인’으로 표시합니다. 2026년 9월 1일부터 중앙선 등이 없는 생활도로의 법정속도가 30km/h로 변경된 규정을 참고했으며, 해당 조건이 명시된 지도 자료에만 기본값을 적용합니다. 표지로 지정된 속도가 우선합니다.

일본에는 과속 자동 단속장비가 있으며 오키나와 경찰의 이동식 장비 운영 자료도 확인했습니다. OSM에 등록된 카메라 8곳을 위치 자료로 연결했습니다. 일부 조사 연도가 오래되어 현재 운영 여부는 확인되지 않았습니다. 누락된 카메라와 이동식 장비 위치를 임의로 만들지 않았습니다. 카메라·일시정지 표지의 장비 모양과 도로변 배치는 단순화되어 있습니다.

제한속도 초과, 신호 위반, 대향차로·일방통행 역주행, 일시정지 미준수, 차량·시설 접촉에 대해 경고와 감점을 표시합니다. 연속된 같은 위반으로 매 프레임 점수가 차감되지는 않습니다. 주차 완료 시 총점, 항목별 횟수·감점, 이동 거리와 시간이 나타납니다. 이는 게임의 연습 평가이며 실제 범칙금·벌점·단속 기준을 의미하지 않습니다. 모든 법규와 보행자 상황을 구현한 운전 교육 인증 프로그램은 아닙니다.
